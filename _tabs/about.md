# About Me

안녕하세요! 시니어 QA 전문가의 기술 블로그에 오신 것을 환영합니다.

## 소개

저는 소프트웨어 품질 보증(QA) 분야에서 다년간의 경험을 쌓아온 QA 엔지니어입니다.

## 전문 분야

- **테스트 자동화**: Selenium, Playwright, Cypress
- **API 테스팅**: REST API, GraphQL
- **성능 테스트**: JMeter, k6, Locust
- **CI/CD**: Jenkins, GitHub Actions, GitLab CI
- **모바일 테스트**: Appium, XCUITest

## 블로그 목적

이 블로그를 통해 QA 분야의 다양한 기술과 베스트 프랙티스를 공유하고, 함께 성장하는 QA 커뮤니티를 만들어가고자 합니다.

## 블로그 소개

이 블로그는 소프트웨어 QA(Quality Assurance) 분야의 다양한 기술과 경험을 공유하기 위해 만들어졌습니다.

### 다룰 주제들

#### 1. 테스트 자동화

| 도구 | 용도 | 언어 |
|------|------|------|
| Selenium | UI 테스트 | Java, Python |
| Playwright | E2E 테스트 | JS, Python |
| Cypress | 프론트엔드 테스트 | JavaScript |
| Appium | 모바일 테스트 | Java, JS |

#### 2. API 테스팅

```python
import requests

def test_api_status():
    response = requests.get("https://api.example.com/health")
    assert response.status_code == 200
```

#### 3. 테스트 전략

- 테스트 케이스 설계 기법
- 리스크 기반 테스팅
- 탐색적 테스팅

#### 4. CI/CD와 테스트

```yaml
# GitHub Actions 예시
name: Test Pipeline
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run tests
        run: pytest
```

#### 5. 성능 테스트

- JMeter를 활용한 부하 테스트
- k6를 활용한 스크립트 기반 성능 테스트
- 성능 모니터링 및 분석
